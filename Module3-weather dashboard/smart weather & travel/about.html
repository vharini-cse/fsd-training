ABOUT THE PROJECT

Smart Weather & Travel Dashboard

A simple web application that combines real-time weather information with useful travel suggestions.

WEATHER MEETS TRAVEL

Make Better Travel Decisions With Weather Information

The Smart Weather & Travel Dashboard is a multipage web application designed to help users check weather conditions before planning a trip.

Users can search for a city, view current weather information, explore upcoming forecasts, and receive travel suggestions based on different weather conditions.

The project demonstrates how JavaScript can communicate with a public weather API and dynamically display real-time information on a responsive website.
